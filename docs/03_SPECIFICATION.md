# Спецификация основных узлов — Этап 2

Документ фиксирует состав и требования к основным комплектующим первого опытного образца. Окончательные артикулы отдельных приводов, аккумулятора и мобильной платформы уточняются после стендовых измерений и получения коммерческих предложений.

| Узел | Основные требования / состав |
|---|---|
| Мобильная платформа | Колёсная база для грунта/неровного покрытия; 4WD; 4WS предпочтительно; полезная нагрузка от 500 кг; открытый CAN/SDK или иной документированный интерфейс; возможность интеграции ROS 2; E-stop и безопасная остановка |
| Манипулятор | Кинематическая цепь Z → J1 yaw → J2 yaw → J3 yaw → J4 pitch → J5 roll; рабочий фланец QC36; обратная связь по положению для осей, где потеря положения критична |
| Вертикальная ось Z | Направляющие; ременной или цепной привод; удержание/тормоз; верхний и нижний аппаратные концевики; окончательный ход определяется по физической компоновке |
| Приводы руки | Шаговые closed-loop либо BLDC/серво подходящего класса; драйверы с Enable и аппаратной остановкой; энкодеры для критичных осей |
| Камера | Intel RealSense D435, Eye-in-Hand; RGB-D; отдельная физическая hand-eye калибровка после сборки |
| Секатор | Готовый электрический секатор; механическое крепление к инструментальному фланцу; изолированное управление спуском; контроль открытого/закрытого положения; контроль тока; защитный кожух; отдельное разрешение включения |
| Обработка места среза | Бак 0,5–1 л; перистальтический насос 12/24 В; силиконовая трубка; обратный клапан; форсунка; MOSFET-ключ; поддон от протечек |
| Локальное управление | STM32-class контроллер либо совместимая промышленная плата; отдельные драйверы осей; CAN или RS-485 между локальными узлами; USB/Ethernet к верхнему компьютеру; дискретные входы концевиков и безопасности |
| Силовая система | Класс 48 В; BMS; главный предохранитель; силовой контактор; DC/DC 48→24 В, 24→12 В, 12→5 В; сервисное отключение; штатное зарядное устройство |
| Безопасность | Две фиксируемые кнопки E-stop с НЗ контактами; силовой контактор; отдельное отключение секатора; механическое удержание оси Z; аппаратные концевики; ручной reset |
| Кабельная система | Кабельные цепи/петли, разъёмы с фиксированными назначениями, разделение силовых и сигнальных линий, сервисное отключение |
| Агрономические датчики | Температура/влажность воздуха, освещённость, влажность и температура грунта; для длинных линий предпочтителен защищённый интерфейс RS-485/Modbus |

## Стандарт интерфейса заменяемого узла

Для каждого заменяемого компонента фиксируются:

- механика: посадочные размеры, отверстия, вал или фланец;
- электрика: напряжение, максимальный ток, разъём;
- управление: PUL/DIR, CAN, RS-485 либо дискретный сигнал;
- данные: единицы измерения и частота обновления;
- безопасность: состояние при обрыве линии и пропадании питания.

## Что уточняется после стенда

До физической сборки и измерений не фиксируются как окончательные: точные модели всех моторов, фактический ход Z, реальные mechanical hard limits J1–J5, окончательная ёмкость аккумулятора, массы/инерции и точная hand-eye extrinsic камеры.
