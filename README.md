# Lemon Robot — Stage 2 Delivery

Комплект сдачи Этапа 2 по договору №1-СЗ/2026 от 23.07.2026.

Договорный результат Этапа 2:

> Цифровая модель, URDF/Xacro, симуляция, спецификация и заявки на основные комплектующие.

В репозитории находятся только материалы, относящиеся к этому результату. Материалы следующих этапов, программное обеспечение распознавания/автономной обрезки, обучающие данные и иные внутренние разработки сюда не включены.

## Состав

- `ros2/lemon_robot_description/` — цифровая модель ROS 2, URDF/Xacro, RViz и Gazebo Harmonic;
- `docs/01_STAGE2_COMPLETION_REPORT.md` — итоговый отчёт;
- `docs/02_DIGITAL_MODEL.md` — описание цифровой модели;
- `docs/03_SPECIFICATION.md` — спецификация основных комплектующих;
- `docs/04_SUPPLIER_REQUESTS.md` — сведения о фактических запросах и ответах поставщиков;
- `docs/05_VALIDATION.md` — порядок проверки результата;
- `scripts/validate_delivery.py` — автоматическая структурная проверка комплекта.

## Базовая среда

Ubuntu 24.04, ROS 2 Jazzy, Gazebo Harmonic.

Подробные команды приведены в `docs/02_DIGITAL_MODEL.md` и `docs/05_VALIDATION.md`.
